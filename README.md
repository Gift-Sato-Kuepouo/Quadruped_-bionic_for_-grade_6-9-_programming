# 🐾 PuppyPi Bionic Quadruped — K–12 Programming & AI Bootcamp (Grades 6–9)

**Puppy Code Academy** — a scaffolded K–12 AI & Robotics initiative where students earn every skill they need to program their own PuppyPi robot dog: Python, sensors, IoT, machine learning, ROS, and SLAM ending in an autonomous, voice- and vision-aware quadruped capstone.

**Robot:** PuppyPi Advanced Kit + Raspberry Pi 5 (4GB) — AI embodied intelligence, ROS-based bionic quadruped with camera vision, voice understanding, SLAM mapping, and autonomous navigation.

##  Who this is for

- **K–12 educators & program coordinators** launching a robotics/AI bootcamp with limited budget and no robotics background required
- **Students (grades 6–9 core track, adaptable K–12)** building a portfolio robot they understand line-by-line
- **Funders & school boards** looking for a measurable, replicable STEM pipeline program
- **Interviewers / collaborators** — the curriculum is designed to be presented and scaled as a stand-alone initiative

##  The skill ladder (at a glance)

```
STAGE 6  ★ CAPSTONE: Autonomous PuppyPi Companion         (Weeks 11–12)
STAGE 5  Robotics & ROS: gait, servos, SLAM, navigation   (Weeks 9–10)
STAGE 4  Machine Learning & Vision: gestures, voice, edge ML (Weeks 7–8)
STAGE 3  IoT & Cloud: MQTT, dashboards, telemetry          (Weeks 5–6)
STAGE 2  Sensors & Electronics: GPIO, ultrasonic, IMU, camera (Weeks 3–4)
STAGE 1  Programming Fundamentals: Python, loops, functions  (Weeks 1–2)
STAGE 0  Digital literacy & computational thinking          (Pre-camp)
```

Every phase's output becomes the next phase's input. Nothing is taught in isolation.

##  Quick start (for students & instructors)

1. **Read** [`PuppyPi_Bootcamp_Curriculum.md`](./PuppyPi_Bootcamp_Curriculum.md) — start with the elevator pitch (Section 1) and the skill ladder (Section 3).
2. **Set up the robot** — PuppyPi Advanced Kit + Raspberry Pi 5 (4GB); see Section 7 (Kit & Logistics) for the full hardware/software stack.
3. **Start Week 1 in the simulator** — no hardware needed. The virtual-pet warm-up runs in any browser/Python environment.
4. **Run the instruments** — grab [`PuppyPi_Survey_Evaluation_Framework.md`](./PuppyPi_Survey_Evaluation_Framework.md) Instrument A1 (Pre-Camp Survey) and A2 (Pre-Camp Skills Check) on Day 1.

##  Impact & evaluation

The program is measured end-to-end: pre/post skill checks, badge completion rates, self-efficacy gains, capstone rubrics, and 3/6-month pathway follow-up. See the evaluation framework for the full KPI dashboard and a copy-paste funder report template.

**Targets:** ≥ 80% badge completion · ≥ 40% skill gain · ≥ +0.8 self-efficacy (5-pt) · ≥ 70% functional capstone demos · NPS ≥ +50 · ≥ 40% continued STEM pathway at 6 months.
